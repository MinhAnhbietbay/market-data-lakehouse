# Standardize Contracts: Core

## Purpose
Contracts for core reference entities.

## What belongs here
- instrument/issuer/exchange/listing schemas
- identifier rules

## What does NOT belong here
- market observations
- alpha fields

## Inputs
Source-aligned raw models.

## Outputs
Core entity contracts.

## Ownership
dbt / data modeling owner

## Examples
- `instrument.md`
- `issuer.md`
