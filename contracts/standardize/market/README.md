# Standardize Contracts: Market

## Purpose
Contracts for market data entities.

## What belongs here
- price observation grains
- corporate action rules
- calendar assumptions

## What does NOT belong here
- raw price API payloads
- portfolio metrics

## Inputs
Raw market data and core entities.

## Outputs
Market entity contracts.

## Ownership
dbt / data modeling owner

## Examples
- `price_observation.md`
- `corporate_action.md`
