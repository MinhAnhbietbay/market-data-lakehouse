# Curated Contracts: Star Schema

## Purpose
Contracts for dimensional serving tables.

## What belongs here
- dimension/fact grains
- foreign keys
- accepted nullability

## What does NOT belong here
- alpha field matrix specs
- raw API schemas

## Inputs
Standardize entity contracts.

## Outputs
Star schema expectations.

## Ownership
dbt / data modeling owner

## Examples
- `dim_security.md`
- `fact_price_daily.md`
