# Curated Contracts: Alpha Fields

## Purpose
Contracts for field-oriented alpha data.

## What belongs here
- field names
- date/symbol coverage
- missing-data behavior
- field groups

## What does NOT belong here
- portfolio simulation logic
- DSL parsing rules

## Inputs
Standardize/curated model outputs and alpha engine needs.

## Outputs
Alpha field expectations for DSL/engine/backtester.

## Ownership
dbt / data modeling owner with alpha engine owner

## Examples
- `price_fields.md`
- `fundamental_fields.md`
